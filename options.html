Protection

Login-page safety

By default DLP Guard suspends itself on login/registration pages so it never touches credential flows. You can relax that here — at your own risk.

File-upload scanning

When you attach a file to an AI chatbot, DLP Guard reads a copy and warns you if it contains secrets — before you send it. It never changes or blocks your file; if you upload anyway, that's recorded in the stats.

Detection categories

Bulk on/off for whole categories. Individual patterns are managed in the Patterns tab. Noisy categories are off by default.

Add a pattern

Edit any built-in detector or add your own — internal ID formats, ticket numbers, token shapes. New patterns can go in a new category (just type its name). Everything runs in the isolated content-script world, never exposed to the page. Edited regexes are screened for catastrophic backtracking before saving.

Export configuration (YAML)

Download a complete YAML snapshot: all settings, custom patterns, protected terms, and the full built-in regex library with your edits applied. Counters and the audit log are not included.

Import configuration (YAML)

Paste an exported YAML config and apply it. This replaces your current settings, custom patterns, terms, and overrides. Custom and edited regexes are re-screened; unsafe ones are dropped.

Reset

Restore all settings to defaults. Custom patterns and terms are removed.
